\section{Product Summary}

{\small
GastoLens is a production-deployed personal finance PWA that removes the
friction of expense logging. Users describe transactions in plain language ---
\textit{``dinner with friends 45 euros''} --- and the built-in NLP engine
automatically extracts the amount, currency, and category. Voice input via
the Web Speech API is also supported. The app is live at
{\color{ncyan}\texttt{gastolens.vercel.app}}, fully authenticated, backed
by Supabase PostgreSQL with Row Level Security, and synchronises in real
time across all devices with zero infrastructure cost (free tiers).
}

\section{NLP Engine}

{\small
The core differentiator of GastoLens is a custom, fully client-side NLP
parser written in vanilla JavaScript. It operates on free-form Spanish text
in three sequential phases:
}

\vspace{4pt}

\begin{tcolorbox}[greenbox]
{\small
\begin{tabular}{@{}cp{13.8cm}@{}}
  {\color{ngreen}\bfseries 1} &
    \textbf{\color{tw}Numeric normalisation} ---
    converts Spanish number words to digits.
    \textit{``treinta y cinco''} $\rightarrow$ \texttt{35}.
    Handles compounds up to the thousands and mixed forms
    (\textit{``dos mil cuatrocientos cincuenta y tres''} $\rightarrow$ \texttt{2453}). \\[4pt]
  {\color{ngreen}\bfseries 2} &
    \textbf{\color{tw}Amount extraction} ---
    multi-layer regex pipeline detects: \texttt{45.00},
    \texttt{45 euros}, \texttt{1.200,50},
    slang currency (\textit{pavos, cholos, leus}) and
    multi-currency symbols (EUR, RON, USD, \$).
    Exchange rates applied automatically on match. \\[4pt]
  {\color{ngreen}\bfseries 3} &
    \textbf{\color{tw}Category scoring} ---
    each token scores against a keyword matrix across all 8 categories
    (40+ subcategories). The category with highest cumulative score wins.
    Ties are resolved by token position weight. \\
\end{tabular}
}
\end{tcolorbox}

\vspace{4pt}

\section{Security Model}

\begin{multicols}{2}
\begin{tcolorbox}[greenbox]
  {\small\bfseries\color{ngreen}Row Level Security (RLS)}\\[3pt]
  {\small\color{tw}
    Enabled on \texttt{public.expenses}.
    Supabase enforces \texttt{auth.uid() = user\_id}
    at the database level. No application code can
    bypass this policy --- even a compromised frontend
    cannot read another user's data.
  }
\end{tcolorbox}

\columnbreak

\begin{tcolorbox}[cyanbox]
  {\small\bfseries\color{ncyan}JWT + Session Management}\\[3pt]
  {\small\color{tw}
    Supabase GoTrue issues signed JWTs on login.
    Tokens auto-refresh before expiry via
    \texttt{onAuthStateChange} listener.
    Sessions persist in \texttt{localStorage}
    with automatic recovery on page load.
  }
\end{tcolorbox}
\end{multicols}

\begin{tcolorbox}[purplebox]
  {\small\bfseries\color{npurple}Transport Security \& API Isolation}\\[3pt]
  {\small\color{tw}
    All client--server traffic uses HTTPS (enforced by Vercel and Supabase).
    The Service Worker is configured to \emph{never} cache cross-origin
    requests --- Supabase API calls always bypass the SW and go directly to
    the network, preventing stale data from being returned.
    Supabase credentials are stored exclusively as environment variables,
    absent from the source repository.
  }
\end{tcolorbox}

\section{Market Opportunity}

{\small
The personal finance app market is valued at \$1.57B (2023, CAGR 5.7\%).
Mint, the dominant free tracker, was shut down in January 2024, leaving
millions of users actively seeking alternatives.
The Spanish-speaking market (500M+ native speakers) has no dominant
dedicated expense tracker: existing competitors either require bank
credentials --- which European users widely distrust --- or lack natural
language input entirely.
}

\section{Monetisation Paths}

\begin{tcolorbox}[orangebox]
{\small
\begin{enumerate}[leftmargin=*,itemsep=3pt,parsep=0pt,topsep=2pt]
  \item \textbf{\color{norange}Subscription (\$4.99--\$9.99/month)} ---
    Add Stripe or LemonSqueezy paywall. Backend is already cloud-based;
    tier enforcement is approximately one weekend of development.

  \item \textbf{\color{norange}Freemium model} ---
    Free up to 50 expenses/month; paid tier unlocks unlimited entries,
    CSV/PDF export, and budget goals (designed but not implemented).

  \item \textbf{\color{norange}English NLP + global reach} ---
    Extending the parser to English takes approximately one week,
    opening the product to the full global personal finance market.

  \item \textbf{\color{norange}Native mobile app} ---
    The React codebase wraps with Capacitor to produce iOS and Android
    binaries for App Store and Google Play distribution.

  \item \textbf{\color{norange}White-label} ---
    Sell the codebase to fintech companies or banks needing a branded
    expense tracker for their customers.
\end{enumerate}
}
\end{tcolorbox}
